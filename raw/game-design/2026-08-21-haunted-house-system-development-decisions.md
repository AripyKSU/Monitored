# 귀신의 집 시스템 개발 사양 합의

> Source: User design feedback in Codex conversation
> Collected: 2026-08-21
> Published: 2026-08-21

## 기존 계획의 폐기

- 기존 간접 지휘 계획은 완전히 폐기한다.
- `Assets/_3DStealthGame/Legacy` 폴더의 코드는 현재 시스템과 다른 코드이므로 설계나 구현의 참고 자료로 사용하지 않고 삭제한다.

## 스토리 진행과 체크포인트

- 실행 중 체크포인트만 필요하다.
- 체크포인트는 스토리 분기에 맞춰 정해진 위치에서 정해진 아이템과 진행 상태를 가진 상태로 부활하게 한다.
- 부활하면 적은 지정된 초기 위치로 돌아가 초기화된다.
- 스토리 이벤트는 특정 방 진입, 특정 아이템 획득, 특정 퍼즐 완료 등 다양한 조건으로 발생할 수 있다.
- 이미 본 대화를 부활 후 다시 보지 않도록 체크포인트 위치를 설계한다.
- 체크포인트의 상세 위치와 내용은 스토리 및 맵 기획이 구체화될 때 결정한다.
- 체크포인트 스냅샷은 메모리에만 저장한다.

## 방과 CCTV

- 방과 이동 연결은 고정 데이터로 둔다.
- 방 하나당 CCTV 카메라 한 대를 둔다.
- 카메라는 캐릭터가 문을 통과하기 시작할 때 다음 방 카메라로 전환한다.
- 플레이어는 화면에 보이는 상호작용 가능한 지점만 클릭해 이동한다.
- 복도도 하나의 방으로 취급한다.
- 상세 방 연결과 맵 데이터는 맵 기획에서 결정한다.

## 클릭 명령

- 화면의 클릭 가능한 대상을 선택하면 대상의 접근 지점으로 이동하고, 도착 직후 대상의 행동을 자동으로 시작한다.
- 이 흐름은 하나의 `TargetCommand`로 구현한다.
- 명령 수행 중에는 다른 클릭을 받지 않는다.
- 명령 수행 중에는 클릭 가능한 지점 UI도 숨긴다.
- 이동 중 목적지 도달 실패나 대상 비활성화는 정상 게임 규칙이 아니라 스테이지 설계 오류로 취급한다.
- 도착 후에는 아이템 획득이나 메시지 표시 등의 결과를 거의 즉시 실행한다.
- 위험 경보 UI는 이동 및 상호작용 중에도 화면 중앙 상단에 계속 표시한다.
- 추격 장면에서는 A 지점으로 이동 중 B 지점을 클릭하는 예외 규칙을 도입할 수 있으나 상세는 추후 결정한다.

## 오브젝트 상호작용

- 초기 대상 유형은 아이템 획득 오브젝트, 방 이동용 문, 아이템 사용 대상이다.
- 아이템 사용 대상에 도착하면 아이템 선택 창을 표시한다.
- 플레이어가 사용할 아이템을 직접 선택한다.
- 잘못된 아이템을 선택하면 해당 물건을 사용할 수 없다는 메시지를 표시한다.
- 문도 잠긴 상태라면 아이템 사용 대상이 될 수 있다.
- 정확한 오브젝트 목록은 스테이지 설계에서 결정한다.
- 간단한 퍼즐을 UI 화면으로 제공할 수 있으나 구체적인 퍼즐 사양은 미확정이다.

## 인벤토리와 일시정지

- 인벤토리는 보유 아이템 기록과 목록 UI 표시만 담당한다.
- 모든 아이템은 고유 아이템이다.
- 사용한 아이템은 인벤토리에서 제거한다.
- Tab 키로 인벤토리를 표시하는 방식을 고려한다.
- 인벤토리 UI 중 일시정지가 필요하면 공용 일시정지 기능을 사용한다.
- 공용 일시정지는 대화 등 스토리 연출에서도 사용할 수 있도록 게임 흐름 Core에서 제공한다.

## 적 순찰

- 적은 맵 기획에서 정한 목적지 목록을 따라 순찰한다.
- 경로는 맵별로 순환 또는 왕복으로 설정할 수 있다.
- 지점별 대기 시간은 단순하게 유지한다.
- 플레이어 진행에 따라 순찰 경로가 바뀔 수 있다.
- 적은 닫힌 문을 열고 이동할 수 있다.
- 이동 속도는 실제 플레이 테스트에서 결정한다.
- 스토리 이벤트에서는 기존 순찰 적을 잠시 비활성화하고, 지정 위치에서 등장하는 별도의 스토리용 적을 활성화할 수 있다.

## 위험 경보

- 위험 경보는 적 순찰 상태로부터 파생한다.
- 기존 1단계 경보는 제거한다.
- 인접 방은 문 하나로 직접 연결된 방이다.
- 적이 인접 방에 있으면 주의 경보를 표시한다.
- 적의 다음 목적지가 현재 방으로 결정되는 순간 긴급 경보를 표시한다.
- 적이 현재 방에 들어온 뒤에도 긴급 경보를 유지한다.
- 경보는 사운드와 화면 중앙 상단 UI로 표현한다.
- 구체적인 경보 이미지는 미확정이다.

## 은신, 포획, 추격

- 은신처를 클릭하면 접근 지점으로 이동한 뒤 은신한다.
- 은신처 도착 전에 적이 방에 들어오면 도착 후 은신 상태로 전환하지 않는다.
- 이 경우 적이 플레이어에게 이동하고, 접촉하면 짧은 포획 애니메이션 후 사망한다.
- 은신 중에는 오른쪽 아래에 은신 해제 버튼만 표시한다.
- 플레이어가 은신 해제 버튼을 클릭하면 은신처 바로 앞으로 나온다.
- 추격 장면의 세부 명령 및 이동 규칙은 추후 결정한다.
